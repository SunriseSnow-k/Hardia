SISTEMA INTELIGENTE OFFLINE — LINUX

Instalar (el programa no necesita sudo):
  1. Descomprima este archivo en una carpeta de Linux (no en una memoria FAT32 o NTFS).
  2. Abra una terminal en la carpeta descomprimida y ejecute:  sh instalar.sh
     Al final ofrece instalar los paquetes recomendados (pide sudo; puede omitirlo).
     Opciones: --con-dependencias (sin preguntar) o --sin-dependencias.
  3. Abra «Sistema Inteligente Offline» desde el menú de aplicaciones.

Desinstalar:  sh desinstalar.sh   (sus datos se conservan)

Pensado para distribuciones de 64 bits recientes (Ubuntu 22.04 o posterior, Debian 12, Fedora,
Linux Mint, Pop!_OS), con escritorio X11 o Wayland. El paquete se genera en Linux con build.sh y
funciona en distribuciones con una glibc igual o más nueva que la del equipo donde se generó (la
mínima está en glibc-minima.txt; el instalador y el colector lo comprueban).

Para leer todo el hardware conviene instalar (el instalador avisa si faltan):
  smartmontools  estado SMART, temperatura y vida útil de los discos
  dmidecode      módulos de memoria RAM
  pciutils       nombre de la tarjeta gráfica
  lm-sensors     temperaturas de la CPU en algunos equipos (sudo sensors-detect --auto)
  polkit         pedir la contraseña de administrador desde el programa (pkexec)

Linux protege algunos datos: el número de serie, el UUID, los módulos de RAM y el SMART solo se
leen como administrador. En el taller use Escanear → «Escanear con permisos»: el escritorio pide la
contraseña una vez y el programa sigue abierto como usuario normal (lo mismo al medir los discos en
la prueba de rendimiento). Para el PC de un cliente use el colector desde una memoria USB
(Escanear → Preparar USB colector): allí se ejecuta  sh colector.sh  y pide sudo.

Datos del programa: ~/.local/share/SistemaDiagnostico (base de datos, reportes, copias, IA).
